# 个人博客/作品集网站设计文档

日期：2026-08-09
状态：已确认（待实现）

## 1. 背景与目标

用户是计算机专业研究生，研究方向为 **AI Agent（智能体 / 大模型应用）**。需要一个用于求职展示的个人网站，展示个人情况、研究方向和项目成果，供面试官或其他人查看。

**核心目标**：网站本身就是一张高质量的"技术名片"——第一印象专业、信息获取高效、项目展示突出。

## 2. 用户画像与需求

- 职业：计算机专业研究生，AI Agent 方向
- 用途：求职展示（面试官 / 其他读者）
- 内容语言：中文为主
- 维护方式：用户有能力维护任何前端，追求最优秀的展示效果；本阶段先做雏形，内容由用户后续补充

### 需求板块（按优先级）

| 优先级 | 板块 | 说明 |
|---|---|---|
| ★★★ | 项目展示 | 核心板块，展示 AI Agent 相关项目，含技术栈、亮点、链接 |
| ★★ | 关于我 | 教育背景、研究方向、求职意向 |
| ★★ | 技能清单 | 技术栈可视化展示 |
| ★★ | 研究/论文 | 发表的论文、参与项目 |
| ★★ | 技术博客 | 文章列表 + 阅读页 |
| ★ | 联系方式 | 邮箱、GitHub、LinkedIn、简历下载 |

## 3. 技术架构

**技术栈**（参考 Starfolio、Nishkarsh Raj、Letter 等高质量开源个人主页的成熟做法）：

| 组成 | 选择 | 理由 |
|---|---|---|
| 框架 | Astro 5 + TypeScript | 内容站最优，默认零 JS，Islands 按需加载 |
| 样式 | Tailwind CSS v4 | 快速构建、设计统一、响应式 |
| 内容 | Content Collections（MDX） | 博客文章用 Markdown 写，自动类型校验 |
| 个人数据 | 单一类型化配置文件 `src/data/profile.ts` | 个人资料集中一处，改数据不碰组件 |
| 图标 | Lucide / 内联 SVG | 轻量、美观 |
| 增强 | SEO（sitemap + OG 图）、RSS、暗色模式（跟随系统） | 专业站标配 |

**核心设计原则**：内容（数据/Markdown）与展示（组件）彻底分离。用户后续加博客、改项目只需改 MD 文件或 `profile.ts`，不碰组件代码。

## 4. 页面结构与路由

多页面结构，首页精炼概览，核心内容分页展开。

| 路由 | 页面 | 内容 |
|---|---|---|
| `/` | 首页 | Hero（姓名、研究方向、定位、CTA）+ 精选项目 2-3 个 + 最新文章 2-3 篇 + 技能速览 |
| `/projects` | 项目展示 ★ | 项目卡片网格：名称、简介、技术栈标签、亮点、GitHub/演示链接；按重要性排序，支持筛选 |
| `/about` | 关于我 | 教育背景、研究方向、求职意向、个人特质 |
| `/skills` | 技能清单 | 分类展示：编程语言、框架库、工具平台 |
| `/research` | 研究/论文 | 论文、参与项目、进行中工作，学术引用样式 |
| `/blog` | 技术博客 | 文章列表 + 单篇阅读页（代码高亮、目录、上下篇） |
| 页脚常驻 | 联系方式 | 邮箱、GitHub、LinkedIn、简历 PDF 下载 |

`/`（首页）与 `/projects`（项目）为两个最重要的页面，重点打磨。

## 5. 视觉设计

风格：**明亮简洁**（类似 Notion / Apple 官网的信息层次感），AI 科技感。

### 配色

| 用途 | 色值 |
|---|---|
| 背景 | `#FFFFFF`，浅区 `#F8FAFC`（slate-50） |
| 主文字 | `#0F172A`（slate-900） |
| 主色 | `#4F46E5`～`#6366F1`（indigo），用于链接、按钮、强调标签 |
| 辅助色 | 绿（成功/状态）、橙（警示），用于标签区分 |

### 字体

- 中文：系统字体栈（苹方 / 思源黑体 / Noto Sans SC）
- 英文/数字：Inter
- 代码：JetBrains Mono（博客代码块）

### 布局与质感

- 卡片圆角 12-16px、极轻投影、hover 上浮 + 阴影加深
- 首页 Hero 居中，项目卡片网格 2-3 列，响应式适配移动端
- 留白是主角，不堆砌信息

### 动效（克制）

- 页面切换平滑过渡
- 卡片滚动进入淡入上移（IntersectionObserver，零依赖）
- 链接/按钮 hover 微交互
- 不搞夸张动画

### 暗色模式

跟随系统自动切换，两个主题均精心调校。

## 6. 内容策略（本阶段）

- **占位/示例内容**：本阶段使用高质量占位数据搭建雏形（示例项目、示例文章、示例技能），保证界面完整美观
- **数据结构即模板**：`profile.ts` 和 MD 文章结构即后续内容填充模板，用户提供真实信息后替换
- 博客先放 1-2 篇示例文章打底

## 7. 部署

- 首选 **Vercel**：免费、Astro 一键部署、自动 HTTPS、持续集成（push 即发布）
- 备选 **GitHub Pages**：配合 GitHub Actions 自动部署
- 支持后续绑定自定义域名

## 8. 交付物

1. 完整 Astro 项目代码（可自行继续维护）
2. 部署后的在线访问地址
3. "如何更新内容"使用说明（加博客、改项目、换简历）
4. 简历 PDF 入口

## 9. 开发流程

1. 搭建 Astro 项目骨架与整体布局
2. 本地预览，确认实际视觉效果
3. 逐项填充/替换内容（用户提供真实信息后）
4. 部署上线

## 10. 范围外（YAGNI）

- 不做：登录系统、评论系统、付费功能
- 不做：多语言（本阶段仅中文）
- 不做：复杂动画与花哨效果
- 不做：自建后端 / 数据库（纯静态站）
