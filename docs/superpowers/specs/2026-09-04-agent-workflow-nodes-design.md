# 首页 Agent 球体能力节点说明书

日期：2026-09-04

状态：用户已确认书面方案；实现、自动检查与独立源码复核完成。线上发布结果以交付消息为准。

## 1. 目标与范围

在首页现有 Agent 球体周围加入三个能力节点，让视觉对象表达与 EvoAgent、OA 相关的工程能力。保留现有球体、轨道、配色、首页文字和页面结构；不增加大标题、口号或长说明。

本次不增加项目入口、聊天功能、实时运行数据、后端、数据库或新依赖，不修改其他页面。沿用既有 Astro、GitHub 和 Vercel 发布流程，不迁移托管平台，不修改访问权限。

## 2. 内容与布局

- 三个节点仅显示单行英文：`Planning`、`Tools`、`Verification`，分别表示任务规划、工具调用、结果验证。
- 桌面端节点错落分布在球体外侧，优先使用左上、右侧、左下的空白区域。细连接线通向球体附近，不穿过标签或球体中心文字。
- 标签使用小号文字、淡描边、轻背景；不做成按钮，不增加点击或悬停后才能获取的信息。
- 节点作为独立的固定布局层，不嵌入旋转轨道或球体倾斜层，确保文字始终保持正向可读。
- 将底部 `runtime verified` 替换为 `Agent workflow`。原绿色成功指示点改为静态的淡蓝装饰点，不再暗示已经完成真实验证。
- 此处为能力关系示意，不声称动画代表真实任务执行或统一适用于所有 Agent 的执行顺序。

## 3. 动画

- 保留现有球体和轨道动画，不提高转速、不增加闪烁。
- 三条连接线轮流出现一个微弱光点，在约九秒的循环中错开播放；光点沿线靠近球体，关联标签轻微提亮后恢复。
- 标签不移动、不旋转、不缩放；光点和提亮不影响布局，优先使用 transform 与 opacity。
- 遵循系统的“减少动态效果”偏好：停止新增光点和循环提亮，保留静态节点、连接线与可读文字。
- 未执行 JavaScript 时，节点和说明仍可见。

## 4. 响应式与可访问性

- 沿用首页 700px 的移动端断点。小屏幕将三个节点移至球体下方，空间不足时允许换行，不横向溢出；隐藏桌面连接线和光点。
- 保留页面现有黑白主题切换，新增标签在两种模式下均清楚可读；不改变首页背景策略。
- 装饰轨道、连接线、光点对辅助技术隐藏；提供一条简洁的静态可访问描述，说明图中展示规划、工具调用和验证能力。
- 不将循环状态设为实时播报区，也不为非交互节点添加键盘焦点。

## 5. 实施边界

- 现有球体位于 `src/pages/index.astro`。只围绕此区域补充节点、连接线与局部样式；如拆分组件，仅拆分新增的节点覆盖层，避免无关重构。
- 节点是静态内容，动画属于本地视觉表现，无网络请求、登录、数据流或持久化状态。
- 无需加载态或服务端错误态；禁用动画时直接展示静态内容。

## 6. 验收

1. 首页存在三个准确标签与 `Agent workflow`，该球体区域不再出现 `runtime verified`。
2. 桌面端文字不随球体或轨道旋转，连接线和标签不会遮挡中心的 `AGENT`。
3. 手机端节点显示在球体下方，无遮挡、裁切或横向溢出。
4. 黑白模式、减少动态效果和无 JavaScript 情况下均可阅读内容。
5. Astro 检查及生产构建通过；新增测试覆盖节点文案、旧状态文案移除及基本可访问语义。
6. 提交并沿用既有发布流程更新网站；分别记录构建、部署状态以及实际完成的验证，不把部署成功等同于视觉验收。
